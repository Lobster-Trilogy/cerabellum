MODE SWITCHES
─────────────
\\ nvl                    switch to NVL narrator mode
\\ adv                    switch to ADV dialogue mode

SCENE & ENVIRONMENT
────────────────────
\\ scene: name            change background
\\ music: name            change music (fadein 1.0)
\\ sfx: name              play sound effect
\\ break                  fade to black, pause

SPRITES
────────
character:: state         show sprite at last known position
character:: state left    show sprite at left
character:: state right   show sprite at right
character:: state center  show sprite at center

character:: state left t_default    standard transition (default)
character:: state left t_weighted   slow transition — emotional moments
character:: state left t_instant    instant — shock / impact
character:: state left t_shake      shake effect

\\ hide: character        hide a sprite
                          ~ note: side image characters hide automatically ♡
                          ~ only use \\ hide: for side image characters
                          ~ if you manually showed them as a full sprite ~
\\ clear                  hide all sprites

CGs
────
\\ cg: name               trigger / show a CG image
\\ hide: cg               hide the current CG

SCRIPT STRUCTURE
─────────────────
\\ label: name            define a Ren'Py label
\\ jump: name             jump to a label
\\ call: name             call a label (returns after)

PYTHON / REN'PY PASSTHROUGH
────────────────────────────
\\ py: command            inject raw Ren'Py / Python
                          e.g. \\ py: unlock_cg("cg_act01_forest")
                          e.g. \\ py: renpy.music.stop(fadeout=2.0)
                          e.g. \\ py: renpy.hide_side_image()
                          e.g. \\ py: renpy.show_side_image()

COMMENTS
─────────
\\ ~ your note here ~     ignored by formatter — human eyes only
\\ note: ~your note~      same — production note, ignored by formatter
